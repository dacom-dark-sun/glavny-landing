# ГЛАВНЫЙ — презентация к защите

Лендинг-презентация решения кейса «Интеллектуальный контроль качества» (КосмоХакатон 2026): платформа управления качеством космического производства.

Статическая страница без сборки и зависимостей: `index.html`, `landing.css`, `landing.js`, шрифты и картинки лежат рядом.

## Запуск

```sh
python3 -m http.server 8000
```

Затем открыть http://127.0.0.1:8000/. Кнопка «Скачать PDF» печатает все слайды через диалог печати браузера. Кнопка «Открыть стенд» ведёт на https://main.coopenomics.world/.

Источник — `frontend/public/landing/` репозитория cosmo-controller, коммит `1c57f438`.
